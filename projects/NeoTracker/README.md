# NeoTracker

Лёгкое приложение для учёта товаров на складе. Простой интерфейс, локальное хранение, без облаков и подписок.

## О проекте

**NeoTracker** — десктопное приложение для ведения учёта товаров на складе.
Создано для малого бизнеса, которому нужна **простая и понятная** альтернатива тяжёлым учётным системам.

### Почему NeoTracker?

- **Простой интерфейс** — разберётся любой сотрудник, без обучения
- **Локальное хранение** — данные не уходят в облако, всё на вашем ПК
- **Один `.exe`-файл** — запустил и пользуешься, без установки Python и зависимостей
- **Без подписок** — купил один раз, работает всегда
- **Красивый UI** — тёмная и светлая темы, крупные кнопки

## Возможности

### Текущие (MVP)

- ✅ Создание и удаление категорий товаров
- ✅ Добавление товаров внутри категорий
- ✅ Карточка товара: название, количество, цена, описание
- ✅ Галочка «Нет в наличии»
- ✅ Общая стоимость склада
- ✅ Стоимость по категории
- ✅ Поиск по названию
- ✅ Экспорт в Excel

### В планах

- 🔜 Вложенные категории (с переключателем «плоско/вложенно»)
- 🔜 Доскональный поиск с отображением пути к товару
- 🔜 Анимации смены темы
- 🔜 Настройка размера кнопок (компактный/крупный)
- 🔜 Импорт из Excel
- 🔜 Резервное копирование БД
- 🔜 Пользовательские поля товаров
- 🔜 Визуальный конструктор шаблонов (долгосрочная цель)

## Установка и запуск

### Требования

- Python 3.10 или выше
- Windows / Linux / macOS

### Шаги

1. **Клонируйте репозиторий:**

   ```bash
   git clone https://github.com/your-username/NeoTracker.git
   cd NeoTracker
   ```

2. **Установите зависимости:**

   ```bash
   pip install -r requirements.txt
   ```

3. **Запустите:**

   ```bash
   python main.py
   ```

База данных создастся автоматически в папке `data/warehouse.db`.

## Сборка в `.exe`

Инструкция появится после завершения MVP.

Планируется использовать **PyInstaller**:

```bash
pyinstaller --onefile --windowed --name NeoTracker main.py
```

Готовый `.exe` будет лежать в папке `dist/`.
