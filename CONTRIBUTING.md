## Как сообщить о баге

1. Проверь, что баг **ещё не** [создан в Issues](https://github.com/Sbeuvadyarik67/NeoLauncher-/issues).
2. Создай новый Issue с **шаблоном** «Bug report».
3. Заполни:
   - **Описание** — что не так.
   - **Как воспроизвести** — шаги.
   - **Ожидаемое поведение** — как должно быть.
   - **Скриншоты** — если можно.
   - **Версия** NeoLauncher, ОС, Python.

## Как предложить фичу

1. Проверь [Issues](https://github.com/Sbeuvadyarik67/NeoLauncher-/issues) — **вдруг уже** предложили.
2. Создай новый Issue с **шаблоном** «Feature request».
3. Опиши:
   - **Что** хочется добавить.
   - **Зачем** это нужно.
   - **Пример** использования.

## Как отправить Pull Request

1. **Форкни** репозиторий.
2. **Создай ветку**:
   ```bash
   git checkout -b feature/my-feature
   ```
3. **Внеси изменения**.
4. **Проверь**, что всё работает.
5. **Закоммить**:
   ```bash
   git commit -m "Add my feature"
   ```
6. **Запушь**:
   ```bash
   git push origin feature/my-feature
   ```
7. **Открой Pull Request** на GitHub.

**Требования к PR:**
- **Описание** — что меняет, зачем.
- **Ссылка** на Issue (если есть).
- **Скриншоты** (если UI).
- **Код** — работает, не ломает существующее.

## Стиль кода

- **Python**: следуй [PEP 8](https://peps.python.org/pep-0008/).
- **Отступы**: 4 пробела.
- **Длина строки**: до 100 символов.
- **Имена**: `snake_case` для функций, `CamelCase` для классов.
- **Комментарии** — на русском или английском.
