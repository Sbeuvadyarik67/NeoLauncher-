# Кодекс поведения

## Общие правила

Этот проект создан для разработки и обсуждения IT-проектов на Python. 
Мы приветствуем конструктивное общение, взаимное уважение 
и обсуждение по существу.

## Разрешено

- Обсуждение проекта, кода, идей, багов.
- Конструктивная критика.
- Предложения по улучшению.
- Вопросы по использованию.

## Запрещено

- Оскорбления, личные атаки, угрозы.
- Троллинг, спам, флуд.
- Разглашение личных данных других людей.
- Публикация контента, нарушающего законодательство РФ.
- **Обсуждение политических, религиозных и иных тем, 
  не относящихся к проекту.** Проект — технический, 
  здесь обсуждаем только IT.
