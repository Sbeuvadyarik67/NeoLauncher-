**NeoBrain Launcher** — это универсальный лаунчер для запуска и управления проектами NeoBrain, NeoSpace и другими AI-приложениями.  
Он объединяет все инструменты в одном месте, предоставляя удобный интерфейс с неоновым дизайном и поддержкой нескольких языков.

## ✨ Особенности

- 🚀 **Запуск проектов** — NeoBrain, NeoSpace, WhyDoes и другие
- 🎨 **Неоновый интерфейс** — 20+ тем оформления
- 🌐 **Поддержка двух языков** — Русский / English
- ⚙️ **Гибкие настройки** — выбор модели, температуры, "кринжометра"
- 🧠 **Управление персонажами** — создание, удаление, генерация
- 🏠 **Комнаты с персонажами** — до 10 участников, 3 режима работы
- 📤 **Шеринг ссылок** — доступ по локальной сети
- 💾 **Долгосрочная память** — SQLite база данных для истории диалогов
- 🎯 **Анимации** — плавные переходы, выезжающие панели

## 🚀 Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/Sbeuvadyarik67/NeoLauncher.git
cd NeoLauncher


Установка зависимостей
bash
pip install -r requirements.txt

Запуск
bash
python launcher.py

🛠️ Использование
Запуск проекта
Откройте лаунчер

Нажмите на карточку нужного проекта

Нажмите кнопку ▶ ЗАПУСТИТЬ

Управление персонажами
➕ Персонаж — создайте персонажа с уникальным именем и стилем

✨ Создать по описанию — AI сгенерирует персонажа по вашему описанию

🗑 Удалить — удалите ненужного персонажа

Комнаты
Создавайте комнаты с 2–10 персонажами

Выбирайте режим: Случайный, Строгий или Перебивание

Указывайте схему ответов для строгого режима

🗂️ Структура проекта
text
NeoBrainLauncher/
├── launcher.py              # Основной скрипт лаунчера
├── manifest.json            # Конфигурация проектов
├── launcher_settings.json   # Настройки пользователя
├── projects/                # Папка с проектами
│   ├── neobrain.py          # NeoBrain — AI-чат
│   ├── neospace.py          # NeoSpace — виртуальная ОС
│   └── whydoes.py           # WhyDoes — генератор безумия
├── avatars/                 # Аватарки персонажей
├── characters/              # JSON-файлы персонажей
├── rooms/                   # JSON-файлы комнат
├── logs/                    # Логи и база памяти
└── locales/                 # Языковые файлы
    ├── ru.json              # Русский язык
    └── en.json              # Английский язык

🎨 Настройка тем

✨ Gold	Золотая тема

Полный список доступен в настройках.

🌐 Локализация
При первом запуске лаунчер предложит выбрать язык:

🇷🇺 Русский

🇬🇧 English

Выбор языка сохраняется — при следующем запуске окно выбора не появляется.

💡 Язык можно изменить в любое время в настройках (⚙️).

📦 Сборка EXE
Для сборки исполняемого файла используется PyInstaller:

bash
pyinstaller --onefile --windowed launcher.py
После сборки EXE-файл появится в папке dist/.
