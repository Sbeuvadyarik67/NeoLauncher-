# 🧠 NeoBrain Launcher

**NeoBrain Launcher** — это центральная панель управления для запуска всех проектов NeoBrain в одном окне.  
Включает в себя **NeoBrain AI Chat**, **NeoReceipt**, **NeoSpace OS** и другие утилиты.

---

## ✨ Особенности

- 🚀 **Быстрый запуск** проектов одним кликом
- 🎨 **Тёмная и светлая темы** (с выбором)
- 🧠 **NeoBrain AI** — локальный чат с персонажами и потоковым режимом
- 📄 **NeoReceipt** — генератор чеков с живым предпросмотром
- 🖥️ **NeoSpace OS** — виртуальная среда для экспериментов
- 🔄 **Автоматическое обновление** проектов через Git

---

### 1. Клонируй репозиторий
```bash
git clone https://github.com/Sbeuvadyarik67/NeoLauncher-.git
cd NeoLauncher-
2. Установи зависимости

🧠 NeoBrain AI Chat
NeoBrain v7.3 — локальный AI-чат с персонажами.

🔥 Возможности:
🎭 Персонажи — создавай персонажей с именем, полом, характером и описанием

⚡ Потоковый режим — буквы появляются плавно (можно отключить)

⏹ Кнопка остановки — остановка генерации в любой момент

🌐 Переключение языков — русский / английский

🎨 Неоновая тема — стильный тёмный интерфейс

🧠 Работает локально через Ollama (без интернета)

📄 NeoReceipt
Генератор чеков с Live Preview.

📊 Мульти-товарные чеки

👁️ Живой предпросмотр

💾 Сохранение шаблонов

🔍 Поиск по истории чеков

🎨 Выбор стиля оформления

🛠️ Технологии
Python 3.12+
